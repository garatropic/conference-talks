## States

Opportunity states: `discovered`, `cfp-open`, `cfp-closed`, `invited`, `past-event`, `cancelled`, or a descriptive evidence note when details are incomplete.

Submission states: `draft` → `submitted` → `accepted` / `rejected` / `withdrawn`; `accepted` → `delivered` / `cancelled`. An invitation does not establish acceptance. Store actual submission timestamps and portal confirmation when available.

## Add a CFP

Use the [GitHub CFP issue form](../.github/ISSUE_TEMPLATE/cfp.yml) for intake if useful. Add its issue URL to the matching opportunity record. The issue is a task; the submission snapshot preserves what was sent.

## Exact title

Beyond the Demo: Building Reliable AI Agents with Gemini and Cloud Run

## Abstract — transcribed from attachment

Getting an AI agent to answer a question is a useful start. Deploying an application people can depend on raises harder questions: What happens when someone closes their browser? Where does the agent’s progress live? Which actions should require human approval?

In this session, we’ll build a customer-facing AI Agent using TypeScript, Gemini, and LangGraph.js, then deploy it to Google Cloud Run. We’ll add persistent state, streamed progress, and an approval step before sending a customer response.

We’ll also explore the deployment decisions behind reliable agent applications: keeping state outside container instances, configuring CPU availability for background work, and managing concurrency as the service scales. Through a live demo, we’ll disconnect the interface, reconnect to the workflow, and approve its next action.

You’ll leave with practical patterns for taking an AI prototype from your laptop to a cloud application that keeps users informed and in control.
